# 2.5.9 交互优化与头像昵称授权排查

日期：2026-11-15。本版本用于提交 Git，未上传微信、未生成 2.5.9 手机预览、未提审或正式发布小程序代码，未更新后端。

## 变更

- 首页去除冗余登录提示和学生继续使用卡片，保留最近共创活动入口。
- 共创点数余额、明细与帮助整合进“我的”，移除共创标题栏点数入口。
- 活动列表标题与进度同行、身份图标置于人数和资料数之前，移除逐项“进入活动”；筛选为全部/收集中/已成文，定稿或发布后显示已成文。
- 共创下一步引导、分享链接重置确认、AI 报价摘要、同步冲突对比。
- 文章本机草稿恢复、预览、保存反馈、历史版本恢复说明；成绩学生快捷切换、录入身份提示、复盘筛选空状态和更多操作。
- 头像区域与文字可点击，增加相册选择和失败反馈，补强不完整资料引导与跨账号回调隔离。
- 保留仅 probe=1 查询启用的 wx.getUserProfile 真机验证面板；该面板只显示返回，不保存或覆盖资料。默认入口不显示。
- 发布打包脚本补入冲突对比模块；归档 2.5.6/2.5.7/2.5.8 预览二维码、清单及验证记录。

## 验收边界

2.5.8 手机截图返回 `getUserProfile:fail api scope is not declared in the privacy agreement`。已在微信公众平台补齐昵称/头像信息类型及头像照片用途，并提交隐私保护指引，刷新后显示“当前协议审核中，不可修改”。这不是小程序代码提审。尚未验证指引生效后是否能一次授权返回真实头像昵称。

模拟器曾出现空白及 getCurrentPagesByDomain 错误；局部模板样式编译通过不能替代视觉与真机验收。后续继续使用 [2.5.8 验证码](../release-2.5.8/profile-probe.jpg)检查真实微信返回。

完整实施记录见 [交互优化记录](../../ux-optimization/2026-11-15-complete-scope.md)。
