# 慧共创 2.1.4 · 交互重设计

日期：2026-11-10。未提审、未发布。

## 问题与设计约束

本版针对用户手机截图中的三个问题重做交互：新增科目流程过重；顶部有两层重复导航和微小返回入口；底部保存按钮与说明竞争。

统一规则：一层导航、一页一个主任务、固定内容由系统提供、详细说明按需查看。主包四页和成绩六页共用一致的导航布局，胶囊区域按设备实际尺寸避让。

## 页面与路径

| 页面 | 主要任务 | 次要入口 |
| --- | --- | --- |
| 首页 | 选择共创或成绩 | 我的 |
| 共创 | 创建、加入或继续活动 | 顶部我的、空态示例 |

左上角房屋图标始终返回产品首页；详情与编辑页面在同组增加返回上一页。删除第二行“慧共创 / 学生 / 保存状态”导航。学生与同步状态只在管理入口展示，避免逐页重复。

## 成绩输入

七科固定列出，每行仅一个分数输入框；移除添加科目、删除科目、手填单科满分、总分与总满分输入。不填的科目不生成 0 分，显式填写 0 分则保留。

默认满分采用长沙中考卷面口径：语数各 120，其余五科卷面各 100；不会将物理等科目的折算满分当作卷面满分。配置及官方来源见 `miniprogram/packages/grades/data/subject-rules.ts`。旧草稿已填写的满分和自定义科目保留，避免迁移丢失。排名换算逻辑不变，未实施不可靠的七科直接求和。

官方依据：https://jyt.hunan.gov.cn/jyt/sjyt/hnsjyksy/web/ksyszzx2/202503/t20250328_33625352.html
