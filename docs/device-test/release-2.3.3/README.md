## 修改

- 全部当前注册页面/自有组件使用同一个 `ui-icon` 组件和 44 枚线性 SVG；导航、状态、工具卡、说明、筛选和展开图标统一。5 个语义色版本只改变颜色，不混用不同轮廓。原生复选框/开关继续使用系统控件。
- 所有带占位提示的输入/文本域显式指定 15px、400 字重；七科输入框的占位文本为空，实际值保留可读字号与常规字重。
- 各科成绩和其他选填默认折叠；折叠保留值。若隐藏分数校验失败，保存时自动展开有问题的科目区，不把错误藏起来。
- 录入页恢复四项底部菜单，选中“录入”；保存按钮独立放在菜单上方，菜单承担底部安全区，正文预留对应高度，避免按钮/菜单/内容叠在一起。
- 切换菜单前立即写入当前账号/学生的草稿，返回继续填写。成功保存后不重新生成旧草稿；身份变化时不把旧表单写入新账号。
- 按钮的文字与图标统一对齐和间距，首页账号信息保持左对齐。
