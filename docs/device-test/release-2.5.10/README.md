# 2.5.10 微信头像昵称快捷填写

日期：2026-11-16。

登录资料页通过微信原生 chooseAvatar 按钮取得用户选择的头像，选择后立即展示；昵称为空时自动聚焦原生 nickname 输入框。新增“使用微信昵称”快捷入口，聚焦后由微信在键盘上方展示昵称，用户点选即填入。状态提示展示头像和昵称是否已填入，点击“使用以上资料并继续”后沿用头像上传、昵称检查、账号资料保存与页面刷新的完整链路。修改资料时按钮显示“保存资料”，原有相册入口和暂时跳过能力保留。

不使用 getUserProfile 默认头像或“微信用户”覆盖资料，不承诺单个授权按钮同时取得两项真实信息。旧接口测试面板仍仅 probe=1 可见，当前预览不显示。

验证：15 项资料测试通过，覆盖原生回调填入、聚焦引导、确认后保存两项及上传重试/账号隔离；13 项交互与游客保存回归通过，小程序 TypeScript 检查及 git diff --check 通过。

正式冻结包入口为首页，manifest.json 对应该包。手机预览使用独立副本，仅将首屏改为登录页并开启 profile=1，以便已有登录账号直接测试资料填写；未发布小程序、未更新后端。

真机验收待确认：扫描 wechat-profile-fill.jpg，选择微信头像，点选键盘上方的微信昵称，确认两项已填入后保存，返回首页及“我的”核对，再重新登录确认资料保留。自动化回调测试与预览编译不替代这些真机操作结果。
