# 手机 UI 调整 · 2026-11-06

用户确认真机可以登录，反馈排版混乱、体验不佳。本轮只整理手机界面与导航交互。

## 修改

- 清除未注册旧页面留下的全局控件样式，新页面统一字体、背景、间距、卡片和表单。
- 提高新页面样式的选择器优先级，覆盖微信 style v2 默认按钮宽度；修复发送按钮越界、表单主按钮和管理项被缩成半宽、返回入口居中等问题。
- 活动标题独占一行区域，长标题自然换行；状态与成员数另起一行。资料、选材、文章、管理统一为下划线标签。
- 资料输入区固定底部，保留安全区；监听键盘高度抬升，照片预览横排。发送成功滚动到最新资料。姓名头像仅显示首字，时间使用简短中文格式。
- 无任务时隐藏生成进度入口。设置项使用明确的左右布局，不再依赖空格对齐。
- 活动标签切换不增加返回层级，切换页面回到顶部；主导航只出现在共创活动与我的页面。
- 精简创建和报价页提示；保持活动名称、选填说明两项，不新增活动属性。

## 验证与边界

- 微信开发者工具实际编译通过。`scripts/device-ui-review.cjs` 在原生模拟器检查 17 个页面/状态，截图位于 `ui-review/`；检查核心控件不横向溢出，主按钮与管理项不会缩成半宽。
- 真实账号只读导航覆盖共创活动、资料、选材、文章空态、管理、成员、邀请、我的、点数。创建、加入、生成、报价、文章正文、编辑、登录、参与者空态使用本地界面数据检查，不调用业务写入接口。
- `scripts/v2-miniprogram.test.cjs` 共 7 项通过，包括发送防重与重试保留、参与者限制、标签返回层级、切页重置键盘高度、模板事件。
- 图片选择、键盘抬升和不同手机系统仍需更新预览包后真机体验确认；本轮未调用付费 AI。
