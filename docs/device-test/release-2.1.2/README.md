# 慧共创 2.1.2

日期：2026-11-09（Asia/Shanghai）。状态：2.1.2 手机预览码已于 2026-11-10 生成，开发者工具验证通过，手机验收等待用户反馈；未上传开发版本、未提审、未发布。用户告知上一版本已提审；本记录不改变旧版本审核状态。

## 变更

- 保留双产品入口，首页增加“我的”统一账号入口。
- 共创新增虚构示例文章和流程说明，游客无需登录即可查看。
- 成绩保存默认写入当前身份、当前学生的本机空间，游客无需登录；不自动开启同步。
- 已主动开启同步时继续同步；断网同步失败不阻止已成功落盘的成绩，账号页可查看并重试。
- 游客资料由用户确认导入账号；保留去重和账号、学生隔离机制。
- 更新保存与隐私提示，提醒本机数据清理风险。

## 打包与提审

运行 `node scripts/prepare-miniprogram-release.cjs`，默认读取 `miniprogram/config/release.json`。输出临时代码目录，文件哈希记录在本目录 manifest.json。后续修改代码必须重新打包，核对清单后上传，微信开发者工具上传版本填写 2.1.2。

真机复核：清除数据后首页不弹授权；两个入口可体验；游客录入并保存后重开仍有记录；取消登录可返回；登录后确认导入两次无重复；退出、换学生不串数据；开启同步后断网保存成功且可重试同步。

提审说明（完成真机复核后使用）：已增加免登录功能体验，用户无需授权即可浏览共创示例、录入并在本机保存成绩。登录由用户自主选择，云端同步主动开启；取消登录仍可继续浏览，头像、昵称、手机号不作为游客体验前置条件。
