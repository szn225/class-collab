# 慧共创 2.3.2：按反馈逐项修正

> 历史版本记录（原位归档）：本文的版本、预览码及验收结论仅对应本轮交付，待验收项不自动关闭。当前状态见 [版本状态](../../STATUS.md)。

日期：2026-11-10。分支 `codex/ui-refinements-2.3.2`。本轮以用户具体问题为范围，不再次统一放大/缩小全部字号。覆盖 2.3.1 规范的调整如下。

## 调整

1. 首页去掉“工具”和底部“我的账号”。顶部显示真实账号称呼、登录状态与登录/账号设置入口；沿用两个业务空间的共同身份，不发额外账号请求、不强制登录。
2. 全部当前注册页面使用纯白背景，次级容器使用中性灰。冲稳保、资料状态等保留局部语义色块，不再用灰绿色铺整页。
3. 两张功能卡均为同一套线性矢量图标、相同尺寸和布局。标题 20px、500 字重，说明 15px，整卡可点。取消一张位图、一张图标的混搭和重复“进入”文字。
4. 活动说明、生成篇幅/语气/重点、公众号发布记录默认折叠，折叠保留输入；不改字段值、服务默认参数或费用规则。既有设置、同步、学校筛选、失分归因仍按需显示。七科成绩按此前明确要求保持直接填写；核心排名条件与保存操作保留。
5. `formatRankDelta` 保留排名算法：负差值是进步，正差值是退步；仅把视觉语义改成进步向上、退步向下。
6. 成绩页顶部取消“最近更新 · 日期 · 考试（口径）”提示，只显示本次考试名一行；详细名称/日期仍可在考试记录和详情查看。设置图标打开原有更多操作，不新增功能。
7. 底部导航内容从 68px 改为 52px；底部保护区最多 20px，当前开发者工具整体 ≤73px；导航文字仍 15px，图标 22px，点击区域覆盖整项。保留底部内容占位，避免列表被遮挡。实际手机底部手势区仍待验收。
8. 设置、筛选、说明和展开/收起使用有可访问名称的图标；保存、登录、生成等重要操作保留明确文字。筛选/展开箭头使用本地 SVG，避免裁剪后的图标字体缺少字形。
