# 用户文章实际排版试验

正文：《聊聊企业AI转型的本质》。八段正文和四张用户配图。原始图片复制到本目录 assets，仅供本地预览，没有上传。

调用项目现有模型一次。模型读取正文及助理根据用户图片整理的客观说明，自主生成正文排版；没有把图片文件直接发送给模型。标题单独显示在复制范围之外。

模型返回的布局、色彩与图片位置未手工重新设计。校验器补充支持原文已有的列表编号，用原响应完成验证，没有重复调用模型。原始输出见 model-result.json，规范化布局见 layout.json，正文片段见 body.html，可打开的预览见 preview.html。

本次实际输入1396 token（缓存命中512），输出1873 token，合计3269 token。

浏览器验证四图均加载、标题不在复制正文中、390px宽度无横向溢出。full-preview.png 是完整页面截图。

图片仍是本地文件，复制到公众号编辑器后应上传配图并检查兼容效果。未修改线上文章或发布内容。

## 复制兼容修正与占位图版本

用户反馈本地图片丢失、分点间距粘贴后变大。增加导出适配器：明确写入各节点字体与行高、去除格式化空白节点、p外边距归零、相邻块留白转换为不叠加的内边距并控制最大16px。浏览器预览和复制使用同一份适配后HTML。

用户随后允许将图片改为占位色块。spacing-fixed-preview.html 与最新 preview.html 已使用四个色块；原图仍保留在 assets，没有重新调用模型或产生新增token。浏览器验证复制内容无img、四处占位完整、标题排除、文字与预览一致、无空段落。尚未在真实公众号编辑器验证粘贴后效果。
