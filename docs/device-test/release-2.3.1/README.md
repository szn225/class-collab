# 慧共创 2.3.1：可读性修正

日期：2026-11-10。分支 `codex/readability-2.3.1`。依据用户对 2.3.0 的手机反馈：字号过小、不同内容比例失衡。新规范见 [UI规范](../../UI规范-2.3.1-可读性.md)。本次未提交审核或发布正式版。

## 规范与实现

主体/字段 17px，辅助信息 15px，输入值 18px，科目分数 20px，分区标题 20px，页面内容标题 24px；顶部导航 18px，底部导航 15px，核心位次 40px。允许图表坐标使用 13px，并保留长按查看数据。正文不再随窄屏 rpx 网格进一步缩小。

放大字号同时增加行距和留白：科目行至少 58px、普通输入框 52px、保存按钮 52px；普通操作 48px、导航单个点击区域 44px。允许滚动与换行，不通过缩小文字塞满首屏。320–360px 的冲稳保布局改纵向，分科条形结果可换两行。仍保留按需展开和真实业务条件。

辅助文字统一加深；蓝色和暖砂文字各自加深到实际浅底上计算对比度 ≥4.5:1。字号 Token 的 WXSS、组件 scope、JSON 与 TS 同步修正；原有小字号局部覆盖一并处理。
