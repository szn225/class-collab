## 实现

- 首页保留两个真实产品入口和账号入口，移除宣传语，使用暖砂、雾蓝和小幅装饰。
- 两个模块统一自定义导航，返回与首页图标独立；保留微信胶囊安全位置与底部安全区。
- 录入采用七科固定行，无总分、满分或逐科添加；考试类型使用选择器，按市/集团/学校类型显示必要字段，补充项默认折叠。
- 未操作的空表单不立即显示必填错误，保存时完整校验；零分、部分科目、旧卷面满分及草稿继续兼容。
- 成绩、冲稳保、参照及复盘使用协调的语义配色；详情同时展示原始分数与得分率，不编造分科涨分。
- 学校筛选与排序按需展开；三个参照分区及真实学校数据保留。
- 共创资料、选材、费用、文章、分享、管理沿用真实业务条件；移除空态宣传和重复说明，不增设自动发布或额外权限。

- TypeScript 类型检查通过；页面路由、组件引用、样式与隔离存储结构检查通过。

- `grades-integration.test.cjs`：17 项集成检查通过，涵盖真实本地 PostgreSQL/API、账号隔离、导入和同步冲突。无生产写入。
- `v2-miniprogram.test.cjs`、`v2-network.test.cjs`：共创权限、发送失败保留资料、登录回跳、返回层级、键盘与网络错误检查通过。
- `grades-device-2.3.0.cjs`：微信开发者工具内验证首页、七科录入、游客保存、重新打开、登录、重复导入、共享身份及主要页面。使用隔离数据和模拟网络，结束恢复原状态。

- 截图均为开发者工具原生渲染。`exam-detail.png` 是最终成绩/零分展示的页面内存夹具检查，其他成绩流程截图来自隔离保存流程。
