# 2.5.5 头像与昵称测试版

日期：2026-11-13（Asia/Shanghai）。原登录页增加个人资料步骤，没有新增注册页面或小程序路由。

## 用户流程

- 新用户微信身份登录成功后，在同一页选择头像、填写昵称，支持跳过。
- 保存资料后首页和“我的”显示头像、昵称；已保存的资料由账号读取，后续登录直接使用。
- 原有已填写姓名的用户继续直接登录，可从“我的”顶部“编辑”进入资料设置。
- 因保存成绩进入登录时，设置或跳过后仍回到原来的待保存成绩，不丢弃表单、不自动导入游客数据。
- 头像使用 chooseAvatar、昵称使用 type=nickname 与 nicknamereview。不是静默读取微信真实头像昵称，不使用 getUserProfile。
- 登录及“我的”的隐私说明已更新为用户主动选择、填写并保存资料。

## 存储与兼容

头像按当前账号生成独立对象路径，复用私有图片存储；只接受 JPEG、PNG、WebP，最大 1 MB。上传凭证、完成确认、资料关联均检查账号归属，不接受客户端任意图片 URL/路径作为头像。上传不确定时可先确认已有文件，避免重复上传卡住重试。

数据库保存头像对象路径，不保存微信临时文件路径；返回限时头像地址，并在临近过期时后台刷新。图片签名失败时降级为默认头像，不阻断账号读取。昵称与头像均可单独保存，旧客户端只更新姓名时保留头像。没有数据库结构迁移、AI 调用或新增扣点。
