# 慧共创共用图标 2.3.3

44 枚基础图标，共用 24×24 网格、1.65px 描边、圆端与圆角。全部为可编辑 SVG，不使用字体字形或位图代替操作图标。包含导航、成绩、录入、复盘、参照、共创资料、选材、分享、账号与状态图标。

默认灰、选中松绿、深色按钮白、进步绿、退步红，共 5 个语义颜色版本。选中态保留同一个轮廓，避免导航中混用实心/线性形状。默认展示 18/20/22px，功能卡 26px，空态 28/32px；点击区域由按钮提供，不能只按图标尺寸设置。

`miniprogram/components/ui-icon` 为两业务共用组件；资源在 `miniprogram/assets/ui/icons`。既有 icon 名称通过显式别名映射到同一套图形。每个实际注册页面与组件的静态名称在测试中核对，避免缺少字形却静默显示为空。

- `icon-sheet.svg`：44 枚图标总览。
- `icon-sheet.html`：本地浏览器总览。
- `scripts/build-ui-icons.py`：可重建资产与总览；本轮直接图标引用也更新为同一套形状。

按钮中图标和文字相距 8px，按钮按角色居中或两端对齐；菜单行标题靠左、状态/展开控件靠右。重要操作保留文字标签，图标自身不重复播报，父按钮提供可访问名称。
