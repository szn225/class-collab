后续已生成 [2.5.6 手机预览二维码](../device-test/release-2.5.6/README.md)，预览包编译成功；手机验收待用户确认。

## 已实施

| 范围 | 最终行为 |
| --- | --- |
| 首页继续使用 | 显示最近查看的共创活动；按用户反馈移除首页学生成绩/草稿快捷卡片。活动信息按账号存储，返回活动时重新校验成员权限 |
| 多学生 | 成绩首页显示学生姓名并可快捷切换，最多展示 5 位学生及管理入口；录入页明确正在为谁填写；切换账号后忽略旧选择回调 |
| 考试类型 | 根据全市统考、集团联考、校内考试说明所需数据与分析范围 |
| 共创下一步 | 管理者在资料页看到任务进行、归档、已定稿、草稿、已有资料和空活动对应的下一步操作；活动列表展示 AI 任务状态 |
| 分享 | 已有链接时突出复制；重置需确认旧链接失效；缺少本机链接时不自动重置 |
| AI 确认 | 汇总选材、篇幅、语气、美化选择、补充要求及支付账户，突出点数上限和冻结/结算规则 |
| 编辑 | 本机草稿暂存、恢复确认、普通正文预览、字数、首尾保存入口、配图移动边界禁用；暂存按账号和活动隔离，保留原版本号防止覆盖其他人的更新 |
| 账号 | 按后续反馈移除共创标题栏点数入口；点数余额、冻结点数、分页明细和共创使用说明整合进统一“我的”页面，个人资料编辑统一前往现有头像昵称页面 |
| 复盘 | 筛选无结果时引导查看全部；全部为空时引导从考试详情创建复盘；提供可见“更多操作”，保留长按捷径 |
| 考试记录 | 提供可见“更多操作”，无需依赖长按发现入口 |
| 历史版本 | 标识当前/历史版本；预览时显示字数、配图数量和是否含 AI 排版；恢复说明新建草稿、保留历史和原分享内容 |
| 状态反馈 | 区分加载与后台更新、文章本机暂存与正式保存；未获 AI 授权/归档时提供原因说明 |

编辑预览展示当前正文和配图的普通排版；手动编辑后原 AI 排版会按既有逻辑清除。未新增分段富文本编辑器或拖拽排序。

- 96 项成绩单元测试通过。
- 5 项页面性能/异步读取测试及 6 项个人资料回归通过。
- 成绩 TypeScript 检查、游客成绩保存和既有交互检查通过。
- 六个修改页面的 WXML 通过微信原生 wcc 编译；六个页面的 WXSS 通过 wcsc 编译。成绩分包样式编译显式传入其导入依赖。
- JavaScript 语法检查及 git diff --check 通过。

## 首页精简反馈

按用户要求，首页不展示登录状态文字，移除学生“继续使用”卡片及其数据读取；“我的”不再显示“账号已登录”，个人资料设置说明移除“已登录”前缀。保留资料设置可跳过等有操作意义的说明。此前生成的 2.5.6 二维码对应修改前的冻结预览包，本次未重新生成二维码。

## 点数入口整合反馈

移除活动共创标题栏的“点数”入口。“我的”新增共创点数余额与可展开明细，冻结点数仅在非零时展示；明细支持分页、失败重试和流水详情，共创使用说明也整合至“我的”。补充测试确认明细分页及账号切换后丢弃旧响应，16 项交互/资料测试、7 项共创检查及相关模板样式编译通过。本次未更新二维码。

## 共创活动列表反馈

列表筛选调整为全部、收集中、已成文。标题置于每项首行，右侧展示进度；身份以图标和文字放到人数/资料数之前，移除列表中的“进入活动”。已成文依据文章定稿/发布状态判断，不再直接使用资料收集状态；文章读取得到定稿结果后同步更新详情页进度。草稿提示待核对。内部暂停、归档的权限控制保持原逻辑，列表不展示这两类标签。17 项交互/异步测试和 7 项共创检查通过，相关模板和样式编译通过；本次未更新预览二维码。

## 头像选择反馈

修复头像选择文字不可点击、“我的”头像无编辑入口及部分资料未完成时跳过设置的问题；增加原生选择失败提示、相册入口和账号隔离。已生成 [2.5.7 最新预览](../device-test/release-2.5.7/README.md)，包含此前各轮反馈；22 项交互/资料测试和7项共创检查通过，微信手机交互待扫码确认。
