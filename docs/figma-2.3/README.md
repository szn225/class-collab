## 本次调整

- 按当前功能与产品原则核对 20 个页面及状态，删除虚构字段、学校、操作入口和无依据的分析结论。
- 录入页直接展示七科成绩；取消总分、满分和逐科添加；其他信息折叠。
- 统一首页入口与返回导航，收敛常驻说明；补齐共创的真实业务流程和权限、费用、不可用状态。
- 使用松绿、雾蓝、暖砂及少量灰紫；统一矢量图标；首页使用一幅小尺寸装饰素材。
