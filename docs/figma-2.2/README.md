设计文件：https://www.figma.com/design/gMe85HAf7xN3cNQzQyEOs1

## 内容

- 「01 用户路径 · 高保真设计」：首页、活动共创、录入成绩、成绩概览、考试详情、复盘、学校参照、成绩设置、我的、登录，共十个主页面（390 × 844）。
- 配套状态：七科区域与数字键盘、按需展开面板、登录前后、复盘完成等。当前共 44 个顶层画板/状态，测得 68 个组件实例、217 个带原型交互的图层。
- 「02 组件 · 颜色 · 字体规范」：8 个本地组件以及颜色、字体规范。

## 关键设计

- 用紧凑列表表单代替大卡片套表单；七科直接列出，一个科目一个成绩框，不填总分和满分，不需要添加科目。
- 顶部只有一层导航，左上提供首页及返回入口，标题只出现一次；移除第二行微小导航和学生状态。
- 保存区仅一个完整宽度的保存按钮；提供键盘打开时的布局状态。
- 说明、备份、学生管理等按需展示。成绩图表使用清晰日期和不重叠数值。
- 保留全市/集团/校内的业务口径。设计示例采用全市位次，示例学校及学生均为虚构。导入文案只描述本机记录及 JSON 备份，不宣称已实现表格导入。

## 检查与修改

确认主设计使用原生文字、矢量、组件、自动布局；检查到 604 个文字、608 个框架、134 个矢量节点，主设计页不存在整页截图或图像填充。界面不是扁平图片。编辑字体采用 Figma 可用的 Noto Sans SC，移动端实现时需适配系统字体和真实设备字宽。

逐页导出并查看十个主页面和键盘状态。修正了全市位次口径、考试类型、示例年份、导入能力文案，并在 Figma 编辑器删除了主指标重叠的重复单位。

记录截图为设计稿导出，不是真机或运行软件截图；原型使用预设内容，不执行实际登录、数据写入或云同步。功能实现和手机验收需要在设计确认后的代码阶段完成。
