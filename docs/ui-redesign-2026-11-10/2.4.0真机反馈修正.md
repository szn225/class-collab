## 本轮实际修改

1. 首页：替换为“参与者提交文字＋参与者提交照片 → 汇成文章”的线描图。图片独立打包，未将入口标题做进图片；保持紧凑卡片和细线风格。
2. 成绩列表：标题与位次独立成行；日期、考试类型一行，参照档次另起一行。消除位次长短导致元信息随机换行的问题，统一标签字重。
3. 录入页：清理该页历史叠加样式，“各科成绩”和“其他信息”合并在同一选填组，采用相同的字号、56px 行高、右侧选填标识与折叠箭头。集团选择内容靠右，与其他字段对齐。
4. 文章页：落地固定底部“更多 / 编辑文章 / 确认定稿（或分享与发布）”操作栏；事实核对与成员可见性归入独立面板。为底部工具栏和安全区留出空间，长文滚动到底时核对项和开关不会被盖住。原定稿核对逻辑与权限保持不变。
5. 新版本整合：版本信息更新到 2.4.0，可在总首页的账号入口进入“我的”，查看底部版本号。干净打包器包含主包共享 styles 和全部新图形资源，并检查 WXSS 引用与静态本地图片是否缺失。
