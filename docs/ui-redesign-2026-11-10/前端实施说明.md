# 线描主题前端实施

> 本文为首次线描实现记录；后续 2.4.0 已上传微信开发版本，尚未确认正式发布，见 [版本状态](../STATUS.md)。下文“没有发布”等描述仅指本次实施阶段。

已将获选的 `总首页设计-v4-线描图形.png` 落地到原生微信小程序，未另建 Web 原型或修改后端。

## 视觉规范

- 暖白底 `#FBF9F5`，白色内容表面；森林绿用于主要操作与共创，墨蓝用于成绩数据。
- 首页采用两张约 150px 高的入口卡片，线描插画为独立透明图片，文字和点击行为由原生组件提供；背景纹路为独立图片。插画没有内嵌文字，加载失败不会影响功能入口。
- 正文和标准控件 16px，辅助信息 15px，区块标题 19px，页面标题 22px。数据主指标保持大字号。辅助文字不低于既有 15px 可读性底线。
- 卡片圆角 16px、控件圆角 10px；1px 边框、无重阴影。主操作至少 48px，导航独立操作至少 44px。
- 页面默认左右间距 20px；小屏首页调整为 16px，插画缩小并降低存在感，保障文字可读。

## 代码范围

- `miniprogram/styles/tokens.wxss`：主包共享视觉变量。
- `miniprogram/pages/home/`：账号栏、两个图形入口、纹路背景；保留账号、登录、活动入口和按有无记录分流的成绩入口。
- `miniprogram/pages/login/`、`pages/account/`：登录、隐私、账号、同步和学生管理统一样式。
- `miniprogram/pages/co-create/`：活动列表、创建、邀请、资料、选材、文章、编辑、版本、生成设置、点数和管理等现有状态统一样式。活动列表明确显示“进入活动”；文章状态独立展示。历史版本、采用资料和重新生成收进原生“更多”菜单，继续调用原有方法。
- `miniprogram/components/app-nav/` 与成绩导航：相同暖白导航和线性图标，保留状态栏、胶囊菜单与安全区处理。
- `miniprogram/packages/grades/`：共享 token、看板、录入、考试详情、复盘、参照、设置与内部导航统一表面、字号、按钮和边框。保留冲稳保、趋势等语义色与计算逻辑。
- `miniprogram/assets/redesign/`：三张生成后按使用尺寸压缩的素材，总计约 304KB。

## 验证方式

使用已登录微信开发者工具的本地模拟器。网络请求替换为本地错误响应，成绩使用独立临时学生空间；会话、原学生列表和待保存数据在 `finally` 恢复，临时学生存储清除。活动界面用本地虚构数据检查视图，没有调用生产接口写入内容。

静态及回归检查包含原生页面与组件引用、全局字号与颜色对比度、TypeScript、活动权限与发送失败重试、访客保存、草稿恢复及成绩集成测试。可复用的模拟器验收脚本为 `scripts/ui-line-theme-device.cjs`，通过 `MINI_WS` 指定开发者工具的自动化端口。

原生截图保存在 `native/`。截图包含开发者工具模拟设备的系统区域，不代表本次重画了系统状态栏或微信菜单。视觉对比见项目根目录 `design-qa.md`。

## 验收边界

没有发布体验版或正式版。模拟器验收不替代不同手机尺寸、系统大字体、微信键盘弹起和真实图片上传的真机复核。演示活动数据仅用于截图；真实活动内容仍由原接口读取。
