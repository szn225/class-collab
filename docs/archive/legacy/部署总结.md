# 班级共创小程序 —— 部署全记录

## 一、部署架构

```
微信小程序 (miniprogram/)
    ↓ 请求
Vercel (Next.js API)  →  DeepSeek AI (文章生成)
    ↓
Supabase (PostgreSQL + 存储)
```

## 二、部署步骤总结

### 1. 数据库（Supabase）
- 创建项目，获取 Project URL、anon key、service_role key
- 在 SQL Editor 执行建表语句
- 创建 Storage bucket: `materials`

### 2. 后端（Vercel）
- 配置环境变量 → `vercel deploy --prod`
- 支持自定义域名或使用 `*.vercel.app` 域名

### 3. 微信小程序
- 修改 `app.js` 中 `baseUrl` 为生产地址
- 在微信公众平台配置服务器域名白名单

## 三、踩坑记录（务必看）

### 🔴 坑1：Supabase Key 格式
**问题**：用户给的 Key 是 `sb_publishable_xxx` 格式，不是 JWT
**原因**：Supabase 的 anon key / service_role key 必须是 JWT 格式（`eyJ...`）
**解决**：到 Project Settings → API 页面重新复制
**教训**：❗ 不要从其他渠道获取 Key，必须从 Supabase 后台复制

### 🔴 坑2：id 字段无默认值
**问题**：`CREATE TABLE` 时 id 字段没设默认值，插入失败报 500
**原因**：Prisma schema 有 `@default(cuid())` 但实际 SQL 没加
**解决**：执行 `ALTER TABLE "User" ALTER COLUMN id SET DEFAULT gen_random_uuid();`
**教训**：❗ 建表 SQL 必须为所有主键 id 设默认值

### 🔴 坑3：环境变量与部署顺序
**问题**：先部署了才设置 Vercel 环境变量，导致第一次部署用的旧值
**解决**：更新 env vars 后必须重新部署
**教训**：❗ 先设好环境变量，再部署

### 🔴 坑4：微信隐私协议（最大的坑）
**问题**：`chooseImage`、`chooseMedia`、`setClipboardData` 全部被拦截
**错误**：`api scope is not declared in the privacy agreement`
**原因**：微信新基础库（3.x）强制隐私合规
**解决**（临时）：绕过改用输入 URL / 浏览器预览页
**解决**（正式）：需要在微信公众平台配置隐私协议
**教训**：❗ 新项目要先配隐私协议再开发

### 🔴 坑5：model:value 双向绑定
**问题**：`<input model:value="{{xxx}}" />` 在某些 lib 版本不生效
**解决**：改用 `<input value="{{xxx}}" bindinput="onInput" />`
**教训**：❗ 尽量用 bindinput 代替 model:value，更稳定

### 🔴 坑6：AI 图片标记格式
**问题**：DeepSeek 输出 `[图片：素材3]` 但正则匹配的是 `[图片：3]`
**解决**：正则改为 `/\[图片[：:]\s*(?:素材\s*)?(\d+)\s*\]/g`
**教训**：❗ prompt 和正则要同步设计，最好限定精确格式

### 🔴 坑7：rich-text 只接受片段
**问题**：`<rich-text>` 组件解析完整 HTML 文档时报错
**解决**：在前端剥离 DOCTYPE、html、head、body 标签
**教训**：❗ `<rich-text nodes="{{...}}">` 只能渲染 HTML 片段

### 🔴 坑8：Vercel 页面路由需根布局
**问题**：在 API 项目中新增页面路由报错
**错误**：`doesn't have a root layout`
**解决**：创建 `app/layout.tsx` 文件
**教训**：❗ Next.js 14 App Router 每个路由组都需要布局
