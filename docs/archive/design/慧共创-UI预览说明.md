# 慧共创新版 UI 预览

对应 PRD：`docs/慧共创-产品需求说明书-PRD-v1.0.md`。

本次交付为独立浏览器交互原型，位于 `ui-preview/`，不改动现有小程序、业务接口、数据库或线上部署。所有数据、生成任务、点数与权限操作均为演示，不具备真实认证或权限隔离能力。界面确认后再进入正式前后端开发。

## 查看

在项目根目录运行：

```sh
python3 -m http.server 4173 --directory ui-preview --bind 127.0.0.1
```

打开 http://127.0.0.1:4173 。也可直接浏览器打开 `ui-preview/index.html`。

顶部切换电脑工作台、小程序预览、平台后台。切换仅用于原型审阅，正式产品的管理空间须独立认证。

## 审阅路径

- 工作台：共创活动 → 创建/邀请码加入（826109）→ 进入活动。
- 活动：资料窗口 → 添加照片、发送、撤回；素材整理 → 单份/批量选材 → 生成确认与模拟任务；文章编辑 → 保存、预览、版本弹窗、定稿提醒、复制演示正文；活动设置 → 状态与成员权限。
- 小程序：共创活动 → 活动资料窗口；我的 → 点数。
- 后台：概览、用户点数调整（原因与二次确认）、活动任务、预算规则、审计记录。

## 确认范围与后续

先确认视觉方向、导航、各终端布局、核心流程与信息表达。图像为装饰占位，活动和计费均为演示数据。版本恢复、微信分享与二维码、身份迁移、真实异步任务、账务审计、后台检索及状态异常全集将在确认后的开发阶段实现；原型中的操作不会持久化，刷新即重置。

现阶段不接入微信身份、AI、付费服务、数据库及公众号正式富文本导出。参数建议值不代表正式承诺。

## 2026-11-05 界面调整（以此为准）

根据本轮确认意见，取消组织者电脑工作台。默认入口为手机端，发起人和协作者在手机上完成活动管理、选材、生成、编辑与定稿。

电脑端仅保留文章链接页面：阅读、复制正文、分享链接；复制后由用户在公众号后台手动发布。原型中通过 `#article` 查看文章链接页。正式公开分享须有可撤销凭证，原型地址仅用于本地审阅。

独立平台后台继续保留，用于运营人员管理用户、点数、预算与审计，不属于活动组织者的工作台。

移除英文标签、宣传横幅、首页统计块、装饰封面与旁栏介绍，改为简洁的活动列表。顶部终端切换栏仅为原型审阅工具，不是正式手机界面。

本轮验证：默认手机入口、手机素材整理、手机文章编辑、分享发布入口及独立文章页的浏览器检查通过。

## 完整手机端交互稿

入口默认从登录开始，顶部“体验角色”和“页面状态”是审阅工具，不属于正式小程序。

### 已覆盖页面与流程

| 范围 | 界面 |
| --- | --- |
| 身份 | 登录、隐私说明、首次填写姓名、登录失败重试、退出后重新登录 |
| 加入 | 邀请码、活动加入确认、邀请中登录与返回、暂停收集提示、归档不可加入、邀请失效 |
| 活动 | 列表筛选、空列表、创建、创建成功、邀请分享、邀请码复制、二维码占位 |
| 资料 | 时间流、成员入口、文字、多图附说明、待发送区、移除图片、图片预览、发送失败保留和重试、自己的资料撤回 |
| 管理 | 活动名称与说明、公告、成员角色、移除成员、协作者与 AI 单独授权、暂停/恢复/归档、重置邀请 |
| 选材 | 类型和状态筛选、单份详情、单项与批量选材、无可用素材拦截 |
| AI | 方式/篇幅/语气/重点、报价、点数不足、未授权、归档、预算暂停、排队/识图/生成/成功/失败/待核实、离开后任务入口 |
| 文章 | 未生成、参与者阅读、成员可见开关、标题正文编辑、配图顺序/移除/说明、保存、未保存离开确认、冲突另存、历史版本与恢复、采用清单、素材变化提醒、人工定稿 |
| 分享发布 | 分享开关与关闭确认、本地文章链接预览、复制正文、复制链接、已发布记录 |
| 个人 | 姓名修改、可用/冻结点数、流水与详情、使用说明 |
| 通用 | 加载、空状态、失败重试、权限不足；角色入口分别展示 |

创建和编辑活动仅保留“活动名称”和选填“活动说明”，不增加封面、分类、标签、报名、地点等属性。公告和收集状态作为必要管理操作保留。

### 演示与验证边界

`mobile-flow.js` 实现本地交互状态。可完整点击体验，刷新后重置。微信登录、分享卡片、二维码、实际上传、AI、账号权限、公开链接凭证、真实账务和富文本导出仍需 UI 确认后接入；当前复制为纯文本，图片为占位或本地预览。

浏览器验证通过：登录和姓名填写；创建表单仅两项；新活动素材/文章为空；发送失败保留文字与重试；任务冻结和结算；成功不关闭收集；保存文章保留旧版本；参与者无管理入口；协作者默认无消费授权；余额不足无确认按钮。主要手机页面在 390px 下无横向溢出。各页面可渲染，不代表微信真机和真实业务验收完成。

浏览器验收脚本：`ui-preview/check-flow.mjs`（用于本次 ego-browser 空间，重新运行时需替换空间 ID）。
