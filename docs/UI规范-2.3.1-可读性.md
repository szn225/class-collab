# 慧共创 UI 规范 2.3.1：先清楚，再精致

日期：2026-11-10。适用于成绩追踪与活动共创全部现有页面。本规范替代 2.3 稿中以 11–13px 辅助文字、密集排版和首屏塞满为目标的做法；功能、权限、计算口径和渐进披露原则不变。

## 1. 字体层级

字号以小程序逻辑 px 标注，不是设备截图的物理像素。正文不再随 750rpx 网格在窄屏上缩小，不使用 zoom、transform 或压缩字距来适配内容。

| 用途 | 字号 / 行高 | 字重 | 示例 |
| --- | --- | --- | --- |
| 页面内容标题 | 24 / 32px | 600 | 产品入口、活动名称、考试名称 |
| 分区标题 | 20 / 28px | 600 | 各科成绩、考试记录、费用确认 |
| 主体内容、字段名称、列表名称 | 17 / 26px | 400；列表名称可 500–600 | 语文、考试日期、学校名称、资料正文 |
| 普通输入值 | 18 / 27px | 400 | 考试名称、日期、位次 |
| 分科分数 | 20 / 26px | 500 | 105、112；零分同样清晰显示 |
| 辅助信息 | 15 / 23px | 400 | 日期、分数单位、状态、错误说明、数据来源 |
| 主操作 | 17 / 24px | 600 | 保存成绩、确认生成 |
| 次操作 | 15–17 / 23–26px | 400–500 | 筛选、详情、撤回 |
| 导航标题 | 18 / 25px | 600 | 录入成绩、学校参照 |
| 底部导航 | 15 / 21px，图标 24px | 选中 600，未选 400 | 成绩、录入、复盘、参照 |
| 页面核心位次 | 40 / 48px | 600 | 5,560，仅用于主要结论 |
| 图表坐标 | 13 / 20px；重点值 15px | 400 / 600 | 日期和位次坐标，仅图表允许低于 15px |
| 共创长文阅读 | 18 / 32px | 400 | 文章正文 |

同一角色在两个业务模块中使用同一字号。层次通过字号、字重、间距与位置共同表达，不能通过把次要文字缩到难以阅读来突出标题。分科值保留数字对齐，但正文使用系统中文字体。

## 2. 信息密度与空间

- 页面左右留白 20px；主要内容区域之间 20px；卡片内边距 20px。首页产品卡片内边距 24px。
- 表单行至少 58px；分科输入框高 44px；普通输入框高 52px。不要靠缩小字段名来同时展示更多行。
- 主按钮高 52px；常规操作至少 48px；导航与少量次操作点击区域至少 44px。图标可以小，点击区域不能随图标一起缩小。
- 录入页保留唯一固定保存按钮，正文预留底部按钮、安全区及额外间距；七科与补充项可滚动，不要求一屏完整展示。
- 页面标题、元信息、状态不重复堆叠。更长的考试名或活动名允许换行。只有顶部导航标题可按可用空间截断，内容区保留完整名称。
- 筛选、备份教程、权限解释等仍按需展开；放大字体不意味着恢复大量常驻说明。

## 3. 小屏适配

- 320–360px 宽度下，冲稳保改为纵向三行，避免三个窄格把学校层级与位次挤碎。
- 小屏各科结果允许两行：科目/成绩在上，得分率横条在下。不能压缩数字或改用小字。
- 章节头、按钮组、状态行、元信息允许换行；输入区与列表正文保持 min-width:0，外围不横向溢出。
- 顶部返回/首页各有独立 44px 点击区域，微信胶囊区域由运行时测量保留。
- 系统字体设置或设备差异还需真机检查。本规范不以开发者工具截图代替手机验收，也不宣称实现了额外的应用内字体设置。

## 4. 颜色与对比

正文 `#263B37`，辅助文字 `#65736B`，底色 `#FAFAF7`。小字号文字不使用浅灰绿作为主要信息色。

主操作松绿 `#245D50`；成绩蓝调整为 `#4D6B82` 搭配 `#EDF2F7`；共创暖砂文字调整为 `#855C35` 搭配 `#F7F0E6`；复盘灰紫 `#756683` 搭配 `#F0EDF5`。颜色保留业务区分，字体层级保持统一。

文字与实际背景的计算对比度应不低于 4.5:1。浅色只用作背景和装饰，不承载重要文字。状态、变化和选中态必须同时有文字或形状提示。

## 5. 实现与验收

- 成绩包字号、行高和触摸尺寸由 design-tokens.wxss 与对应 JSON/TS 运行文件统一；组件 scope 文件同源更新。主包按相同角色规范配置。
- 删除或修正覆盖规范的局部 11–13px 字号，不能只修改全局变量后假定所有页面生效。
- 开发者工具读取实际 computed font-size，核对首页标题 24px、正文 17px、录入字段 17px、成绩值 20px、底部导航 15px、科目行 ≥58px、保存按钮 ≥52px。
- 再次检查长文本、部分科目、零分、字段错误、三种考试口径、底部遮挡、返回与保存。不增加虚构业务数据或操作。
- 视觉规范通过标准是手机上无需放大即可读清主要内容，且标题、内容、状态、操作有明确比例。需要手机反馈后才能确认最终可读性验收通过。
