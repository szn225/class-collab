后续正式域名发布：已确认线上小程序为 2.1.1，并完成对应上传包与当前后端的兼容性核验。正式域名已迁移至本项目，后台入口为 https://gongchuang.chaohuiwan.com.cn/manage 。原 gongchuang-test 域名保留供已发布小程序继续访问。见 client-compatibility.md、formal-domain.json；上段为最初后台部署范围的历史记录。

## 完成内容

- 六个导航模块：运行概览、用户与点数、活动、AI 任务、规则与预算、审计。历史认领移到用户次级入口。
- 白底、16–17px 正文/表格、同套线性图标；用户/任务使用结构化抽屉；高级参数、技术标识和历史配置按需展开。
- 用户、活动、任务、审计在服务端筛选与分页；账本按用户、流水/关联标识或原因查询。审计先筛选再分页，不受旧版先取 500 条限制。
- 点数核对前后余额、冻结余额和原因；并发余额变化要求重新读取。危险操作保留稳定 requestId，超时后查询原操作回执或重试同一操作；未确认操作可在会话中恢复，不重新生成新操作。
- 配置分组编辑、差异核对、版本冲突、恢复为新版本；不改已有任务报价和账本。任务核实仍只处理 review 状态，不重新调用供应商。
- 预算按服务端实际北京时间算法计算，包含跨日仍在途的预占。每日零预算与每月零表示不限分开处理。按模型用量估算与保守成本占用分开；缺少用量时显示待核对，不编造账单数值。
- 新查询接口采用字段白名单，不返回原始微信标识、资料正文、任务输入或学生成绩。未新增成绩管理或多管理员角色权限。
