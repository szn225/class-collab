- 原版 JSON 备份可导入当前学生；整合版备份升级至 schemaVersion 2，附带草稿、画像和考试标记等附加资料。备份恢复通过单次本机文档写入保证原子性。

## 数据库与接口

复用原后端部署与身份验证。新增 `backend/src/lib/v2/grades.ts`，从现有 `/api/v2/grades/...` 路由处理：

| 操作 | 作用 |
| --- | --- |
| students.list | 读取当前账号的云端学生档案 |
| students.create | 将当前本机学生档案登记到当前账号 |
| workspace.get | 读取指定学生的完整版本 |
| workspace.save | 按期望版本原子保存，支持同操作编号重试 |

执行 `backend/prisma/hui-grades.sql` 建立独立的学生、考试、复盘、工作区和操作回执表。工作区保留完整原始存储文档及统一 revision；同一数据库事务更新考试/复盘条目和删除标记。个人资料不放入现有共创聚合状态；活动成员接口不访问成绩表。所有成绩接口从会话取得归属用户，不接受客户端指定所有者。匿名数据库角色无表访问和 RPC 调用权限。

云同步按“当前学生完整资料”检查冲突，不自动合并多设备不同字段。当前版本资料限 1.5 MB、单学生考试 2000 条、计划 5000 条，每账号最多 20 个学生；超过限制保留本机内容并显示错误。不同设备对同一资料有修改时，必须先处理冲突。

## 本地验证

TypeScript 与 Vitest 均由主工程 `backend/package.json` 声明，使用锁文件安装，不依赖旧独立工程。首次运行 `npm --prefix backend ci` 安装依赖。Vitest 5 要求 Node.js `^22.12.0 || ^24.0.0 || >=26.0.0`，本次使用 24.16.0。

```sh
node backend/node_modules/typescript/bin/tsc -p miniprogram/tsconfig.json
node backend/node_modules/typescript/bin/tsc -p backend/tsconfig.json --noEmit --incremental false
node scripts/grades-structure.test.cjs
npm --prefix backend test
npm --prefix backend run test:grades:unit
```

`test:grades:unit` 使用 `backend/vitest.grades.config.mjs`，只扫描主工程 `miniprogram/packages/grades/core` 与 `datasource` 下的 7 个测试文件。测试覆盖换算、位次、档次边界、趋势口径隔离、录入校验、数据集及本地存储；不连接生产服务、不需要微信或数据库。

现有 `npm --prefix backend run test:grades` 仍用于数据库与 HTTP 集成测试，需要下方额外依赖，与内核单测分开运行。

2026-11-11 独立入口验证：7 个测试文件、96 项全部通过，运行时根目录为主工程 `miniprogram/packages/grades/`；未使用旧工程的代码、依赖或配置。

独立临时测试依赖（不参与小程序打包）：

```sh
npm install --prefix /private/tmp/hui-grades-verify --no-audit --no-fund @electric-sql/pglite miniprogram-automator
node scripts/grades-integration.test.cjs
node scripts/grades-device-check.cjs
```

`HUI_TEST_DEPS` 可指定其他测试 node_modules 目录。数据库联调使用本地 PostgreSQL WASM 引擎执行真实增量 SQL，再串联真实 HTTP 路由和迁入的业务服务，不连接生产数据库。覆盖游客录入、导入去重、备份写入失败回滚、跨账号和学生隔离、伪造归属、冲突、响应丢失重试、删除与旧版本保护、异步保存时切换账号、匿名权限和只读示例隔离。

设备脚本连接本机微信开发者工具，检查首页、共创演示、成绩页面及账号页；新增仅用于测试的本机学生档案，验证录入后返回有数据的定位页和示例趋势。截图保存于 `docs/device-test/grades/`。不上传、不提审、不调用付费模型。
